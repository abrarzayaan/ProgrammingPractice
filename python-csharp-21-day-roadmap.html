Python + C# — ২১ দিনের Foundation Roadmap

লক্ষ্য: Python-এ fluent হওয়া, C# দিয়ে একই concept compare করা, এবং library ছাড়া core programming ও OOP foundation শক্ত করা। প্রতিদিনের কাজ শেষ হলে টিক দিন—অগ্রগতি এই browser-এ save থাকবে।

0 / 21 দিন সম্পন্ন

Phase 1 — Basic Foundation (Day 1–7)

Programming-এর মৌলিক logic, control flow এবং input/output বুঝুন।

Phase 2 — Intermediate (Day 8–14)

Reusable code, collections এবং problem-solving habit তৈরি করুন।

Phase 3 — Advanced Foundation & OOP (Day 15–21)

Object-oriented design, errors, files এবং complete console project।

প্রতিদিনের Rule

  • প্রথমে problem ও pseudocode লিখুন, তারপর Python-এ solve করুন, শেষে একই solution C#-এ লিখুন।
  • একটি “Syntax Difference Notebook” রাখুন: typing, block, function, collection, OOP—প্রতিটি পার্থক্য লিখুন।
  • প্রতিদিন অন্তত 2–3 ঘণ্টা: 45 মিনিট concept, 90 মিনিট coding, 15 মিনিট নিজের code review।
  • Library/framework নয়; শুধু language core এবং built-in features ব্যবহার করুন।

Tip: সব checkbox browser-এর local storage-এ থাকে। অন্য browser/device-এ গেলে progress আলাদা থাকবে।
