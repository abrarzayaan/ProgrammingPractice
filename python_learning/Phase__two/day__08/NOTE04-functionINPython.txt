if we write main function in python then! is the main function behave same as like c/c++ ( special entry-point)???
answer: না—Python-এ main() লিখলেও সেটি C/C++-এর main()-এর মতো special entry-point function হয়ে যায় না। Python-এর main একটি সাধারণ function name; 
তুমি call না করলে সেটি চলবে না। Python program শুরু করে entry module-এর top-level code execute করে।

পাইথনে main() না থাকলে আসলে কী ঘটে?
C-তে পুরো কোড কম্পাইল হয়ে মেশিনের বাইনারি ফাইল তৈরি হয় এবং OS সরাসরি _start হয়ে main() খোঁজে। কিন্তু পাইথন একটি ইন্টারপ্রেটেড স্ক্রিপ্টিং ল্যাঙ্গুয়েজ।

পাইথন যখন কোনো ফাইল এক্সিকিউট করে:
 - পাইথন ইন্টারপ্রেটার (python.exe বা CPython) ফাইলের প্রথম লাইনে গিয়ে বসে।
 - সে কোনো নির্দিষ্ট ফাংশন খোঁজে না; বরং ফাইলের লাইন ১ থেকে শেষ লাইন পর্যন্ত টপ-টু-বটম (Top-to-Bottom) সরাসরি এক্সিকিউট করতে করতে নিচে নামে।
 - পাইথনে ফাইলের একদম গ্লোবাল লেভেল (যেখানে কোনো ইনডেন্টেশন নেই) নিজেই একটি এক্সিকিউশন কন্টেক্সট। একে বলা হয় Module Scope বা গ্লোবাল ফ্রেম।

__code__(01):
{
    print("১. এটা আগে রান হবে")

    def my_func():
        print("ফাংশনের ভেতরের কোড")

    print("২. এটা ফাংশন ডিফাইনের পর পরই রান হবে")
}
ইন্টারপ্রেটার লাইন ১ প্রিন্ট করবে, এরপর def দেখে হিপে ফাংশন অবজেক্ট বানিয়ে গ্লোবাল নেইমস্পেসে বাইন্ড করবে, তারপর সাথে সাথে লাইন ৫ প্রিন্ট করবে। কোনো main() খোঁজার প্রয়োজনই তার নেই।

পাইথনে যদি আমরা main() লিখি, তবে কি CPU আগে তাকেই এক্সিকিউট করবে?
উত্তর: একদম না।
আমরা পাইথনে যে প্রচলিত প্যাটার্নটি দেখি:
__code__(02):
{
    def main():
    print("Hello from main")

    if __name__ == "__main__":
        main()
}
এখানে কী ঘটছে মেমরি ও ইন্টারপ্রেটার লেভেলে দেখা যাক:

 1. ইন্টারপ্রেটার লাইনে লাইনে চলে: যখন পাইথন ফাইলটি পড়ে, সে def main(): দেখে। সি-এর মতো CPU লাফ দিয়ে আগে main()-এ যায় না। 
 পাইথন শুধু মেমরিতে main নামের একটি PyFunctionObject তৈরি করে রেখে পরের লাইনে চলে যায়।

 2. __name__ কী? পাইথন যখনই কোনো ফাইল রান করে, ইন্টারপ্রেটার নিজে থেকেই মেমরির গ্লোবাল ডিকশনারিতে কিছু স্পেশাল ভ্যারিয়েবল ইনজেক্ট করে। তার মধ্যে একটি হলো __name__।
  > যদি ফাইলটি সরাসরি টার্মিনাল থেকে রান করা হয় (python script.py), তবে পাইথন ইন্টারপ্রেটার গোপনে সেট করে: __name__ = "__main__".
  > আর ফাইলটি যদি অন্য কোনো ফাইলে import করা হয়, তবে সেট হয়: __name__ = "script" (ফাইলের নাম)।

 3. সাধারণ শর্ত পূরণ: if __name__ == "__main__": হলো সাধারণ একটি if কন্ডিশন। যেহেতু কন্ডিশন সত্য হয়, ইন্টারপ্রেটার ভেতর ঢুকে main()-কে সাধারণ ফাংশনের মতো কল করে।

মূল সত্য: পাইথনের main() কোনো স্পেশাল এন্ট্রি পয়েন্ট নয়; এটি কেবল প্রোগ্রামারদের দেওয়া একটি সাধারণ নাম মাত্র। 
আপনি এর নাম def start(): বা def amar_code(): দিয়ে নিচে amar_code() কল করলেও প্রোগ্রাম হুবহু একই কাজ করবে। 
CPU বা পাইথন ইন্টারপ্রেটার main নামটিকে কোনো বাড়তি প্রটোকল দেয় না।
